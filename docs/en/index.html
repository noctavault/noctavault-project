How it works

Post-quantum

Identity and encryption rely on ML-KEM-1024 (confidentiality) and ML-DSA-65 (signatures), two NIST-standardized primitives via PQClean.

No block, no mining

Every transaction self-authenticates via signature and applies directly on receipt. Propagated by gossip: a duplicate is dropped, which stops flooding on its own.

Multi-recipient sharing

The file key is separately encapsulated for each recipient under their public key — the key itself never travels in the clear.

Anti-spam without PoW

A simple per-identity rate limit (transactions per minute) replaces proof of work.

Architecture

crates/
  nv-core/   post-quantum identity, .nvault and .nvid file formats
  nv-chain/  ledger of signed transactions, rate limiting, revocation
  nv-net/    network: gossip, sync, mDNS/PEX
  nv-node/   CLI (init/add/get/ls/revoke/id/daemon)
apps/nv-app/ desktop GUI (Tauri; Android planned)
