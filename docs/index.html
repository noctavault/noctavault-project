🌒 Noctavault

English

Cloud de fichiers chiffrés, résistant post-quantique, sur un réseau public mondial : pas d'autorité centrale, n'importe qui peut faire tourner un nœud et rejoindre le réseau.

Voir sur GitHub Installation 
curl -fsSL https://raw.githubusercontent.com/noctavault/noctavault-project/main/get.sh | sh

Comment ça marche

Post-quantique

Identité et chiffrement reposent sur ML-KEM-1024 (confidentialité) et ML-DSA-65 (signature), deux primitives normalisées NIST via PQClean.

Sans bloc ni minage

Chaque transaction s'authentifie elle-même par signature et s'applique directement dès réception. Diffusion par gossip : un doublon est ignoré, ce qui arrête l'inondation toute seule.

Partage multi-destinataires

La clé de fichier est encapsulée séparément pour chaque destinataire via sa clé publique — sans jamais faire circuler la clé en clair.

Anti-spam sans PoW

Une simple limite de débit par identité (transactions par minute) remplace la preuve de travail.

Architecture

crates/
  nv-core/   identité post-quantique, format de fichier .nvault et .nvid
  nv-chain/  ledger de transactions signées, rate-limit, révocation
  nv-net/    réseau : gossip, synchronisation, mDNS/PEX
  nv-node/   CLI (init/add/get/ls/revoke/id/daemon)
apps/nv-app/ interface graphique (Tauri, desktop ; Android à venir)
